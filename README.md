# МедГарант — прототип анімації головної сторінки

## Що включено
- index.html, styles.css, script.js — інтерактивний desktop-прототип (1440px), включно з послідовністю Hero (контактна панель — остання), скрол-анімацією About, reveal для Values, hover Services, CTA та каруселлю відгуків.
- assets/ — зображення, витягнуті з наданого PDF.
- medgarant-homepage-animation.mp4 — відеодемонстрація (1920×1080, 20 FPS, 26 секунд).
- render_fallback.py — офлайн-рендер відео на базі PDF, використаний через обмеження середовища браузера.
- record.py — скрипт браузерного захоплення, який можна запускати у звичайному локальному Chromium/Playwright середовищі.

## Перегляд
Відкрийте `index.html` у браузері (або запустіть локальний HTTP-сервер `python -m http.server 8000` у цій папці). Для відтворення відео використовуйте MP4.

## Обмеження
Це робочий motion-прототип, а не pixel-perfect експорт усіх Figma шарів. SVG-маска зуба апроксимована CSS clip-path; шрифт може відрізнятися від Figma. Відео зібране із вихідного PDF через обмеження Chromium у поточному середовищі, тому частина переходів у відео наближена, тоді як HTML-прототип містить інтерактивні ефекти.
